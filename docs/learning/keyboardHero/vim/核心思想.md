# Vim 的核心思想：把编辑当作一门文本操作语言

在 [Vim 起步](./起步.md) 中，你已经用过 Normal 模式，也试过 `w` 移动到下一个单词、`$` 移动到行尾。现在可以回头看一件更有意思的事：这些按键为什么能和删除、修改等动作组合起来？

Vim 不是“用快捷键编辑文本”。更准确地说，它让你在 Normal 模式中说出一句对文本的操作：**做什么**，以及**做到哪里**。这也是为什么许多命令看起来很短，却能组合出很多用途。

## 一次编辑是一句话

以 `dw` 为例：

```text
d + w
│   │
│   └─ motion：移动到下一个 word
│
└──── operator：delete
```

这里的 operator 和 motion 只是给两类按键起的名字，不需要先背术语：`d` 表示 delete；`w` 是你已经用过的移动动作，表示移动到下一个 word 的开头。合在一起，`dw` 的意思就是：从当前位置删除到下一个 word 的开头。在常见的单词边界上使用时，它通常会删除当前单词及其后的空白。

这套读法比“`dw` 等于删除一个单词”更有用：当你知道 `d` 和 `w` 各自的含义，就能自然理解许多新组合。

## 把已经会的动作换进来

保持同一个 `w`，换一个编辑动作，目标就会以不同方式被处理：

| 组合 | 可以这样理解 | 结果 |
| --- | --- | --- |
| `dw` | delete + word motion | 删除到下一个 word 的开头。 |
| `cw` | change + word motion | 删除这一段并进入 Insert 模式，准备改写。 |
| `yw` | yank + word motion | 复制到下一个 word 的开头。 |

保持同一个 `d`，换成你已经练过的其他移动动作，删除范围也会改变：

| 组合 | 可以这样理解 | 结果 |
| --- | --- | --- |
| `dw` | delete + 到下一个 word | 删除一个单词范围。 |
| `d$` | delete + 到本行结尾 | 删除从光标到行尾的内容。 |
| `d0` | delete + 到本行开头 | 删除从光标到行首的内容。 |

所以，面对一个陌生组合时，可以先停一下：第一个键要做什么？后面的键决定范围，还是决定移动？答案往往已经包含在命令里。

## 数量：让一次操作作用得更远

有时你不只想处理一个范围，还想明确处理几个。可以把一个可选的数字放在编辑动作或移动动作前：

```text
[count] operator [count] motion
```

方括号表示这一部分可选。先从已经熟悉的 `d` 和 `w` 开始看：

| 命令 | 可以这样读 | 结果 |
| --- | --- | --- |
| `dw` | 删除到下一个 word | 删除一个 word 范围。 |
| `d2w` | 删除两个 word | 删除两个 word 范围。 |
| `2dw` | 删除两个 word | 删除两个 word 范围。 |
| `cw` | 修改一个 word | 删除一个 word 范围并进入 Insert 模式。 |
| `yw` | 复制一个 word | 复制一个 word 范围。 |

对 `w` 这样的移动动作来说，`d2w` 和 `2dw` 的结果相同。刚开始练习时，推荐优先写 `2dw`：把它读成“删除两个 word”最直接。

如果编辑动作和移动动作前都带数字，两个数字会相乘。例如 `2d3w` 表示删除六个 word。现在只要知道这条规则即可；实际编辑时先从一个数字的组合练起。

## 再往前一步：按内容操作

到这里，先不用继续增加命令。以后你会接触到文本对象：它让你不只按位置移动，还可以直接指定一块内容，例如一个单词、括号中的内容或引号中的内容。

现在只要记住这个方向：Vim 关心的不是光标逐个字符怎样走，而是你希望对哪一段文本做什么。

## 学习时，把组合读出来

刚开始练习时，建议每次按键前在心里把它读成一句话：

- `d`：删除。
- `w`：移动到下一个 word。
- `dw`：删除到下一个 word。

这样练习的目标不是尽快摆脱思考，而是逐渐让“操作 + 范围”成为直觉。等组合变得熟悉后，你会发现自己不是在回忆快捷键表，而是在用一门简洁的语言处理文本。

接下来，把 `dw`、`cw` 或 `d$` 放进自己的安全练习文本中试一次。按错时先按 `Esc`，再用 `u` 撤销；重点是把组合读成一句完整的话，而不是一次记住所有命令。
