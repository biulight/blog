# 后续主题：Buffer、Window、Tab Page 与折叠

这不是 MVP 的必修章节。完成 [综合练习](./综合练习.md) 后，再学习这些主题会更自然。

## 三个容易混淆的概念

```text
Buffer   = 内存中的文本对象，可能与文件关联
Window   = 显示某个 Buffer 的视图
Tab Page = 一组 Window 布局
```

因此，Vim 的 Tab Page 不是传统 GUI 编辑器中“一个 Tab 对应一个文件”的同义词。IDE 的 Vim Mode 往往把
文件标签、编辑器分栏和 Vim 命令映射成自己的模型，使用前应查看该环境说明。

## 折叠

折叠用于临时隐藏不需要阅读的文本范围，帮助你把注意力放在当前结构。折叠方式与快捷键会受 Vim 配置、
文件类型和宿主应用影响；它不属于基础编辑语言的前置能力。

先把 Motion、Text Object、Search 和 Repeat 用熟。需要时再从原生 Vim / Neovim 的帮助或当前编辑器文档
学习 Buffer 管理、Window 分栏、Tab Page 和折叠设置。
