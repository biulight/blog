# 产品手册

这里汇集 Biulight 产品面向最终用户的安装、操作、配置和故障排查文档。

## 已发布

- [Shine](/products/shine)：管理 shell 脚本、应用配置和系统初始化预设的跨平台命令行工具。

## 正在整理

- **Deskmesh**：在 macOS 和 Windows 设备间共享键盘、鼠标和剪贴板。
- **Lumeport**：基于 Tauri 的桌面视频下载工具。

产品代码仓库负责定义真实行为，本站负责提供按用户任务组织的说明。如果手册与当前版本的程序表现不一致，请以程序的 `--help` 和发布说明为准，并反馈文档问题。
